# Портфоліо українською — інструкція

## Як відкрити
1. Розпакуйте архів у будь-яку папку.
2. Відкрийте `index.html` у браузері (Chrome, Edge або Firefox).
3. Для редагування відкрийте папку у VS Code або Cursor.

## Де змінювати вміст
- `index.html` — тексти, назви проєктів, кнопки, відгуки, контактна форма та посилання на зображення.
- `styles.css` — кольори, шрифти, відступи, розміри, адаптивність.
- `script.js` — мобільне меню, кнопки каруселі та демонстраційна поведінка форми.

## Як замінити фото
Знайдіть в `index.html` потрібний тег `<img ...>`. Змініть значення `src` на адресу свого фото або на шлях до локального файлу, наприклад:
`src="assets/my-photo.jpg"`
Створіть папку `assets` і покладіть туди зображення. Для стабільної роботи краще використовувати власні файли, а не зовнішні посилання.

## Важливо
- Макет адаптується під комп’ютер, планшет і телефон.
- Форма перевіряє поля та показує повідомлення, але поки що не надсилає листи. Для реального надсилання потрібно під’єднати бекенд або сервіс форм.
- Відгуки в шаблоні демонстраційні — замініть їх справжніми перед публікацією.
- Зображення зараз завантажуються з Unsplash через інтернет. Їх можна замінити власними фотографіями.

## Як персоналізувати
1. У верхній частині `index.html` змініть ім’я та опис.
2. Замініть фото головного екрану на власний портрет.
3. У кожному блоці «Кейси та проєкти» змініть заголовок, опис і зображення.
4. Додайте реальні посилання на Instagram, Behance або інші майданчики.
